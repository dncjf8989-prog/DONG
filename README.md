# DONG - 섯다 온라인

피망섯다 스타일의 화투 섯다 게임을 4~5인이 실시간으로 즐길 수 있는 웹 멀티플레이 버전입니다.
Node.js + Express + Socket.IO로 만든 서버가 게임 상태(카드, 베팅, 족보 판정)를 관리하고,
여러 브라우저 탭/기기에서 접속해 같은 방에서 함께 플레이할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 후, 닉네임을 입력하고 방을 만들거나
방 코드로 참가하세요. 여러 브라우저 탭(또는 다른 기기)으로 같은 방 코드에 참가하면
바로 멀티플레이가 됩니다.

## 게임 규칙 (요약)

- 2장의 화투 카드로 족보를 겨루는 전통 섯다 방식 (1~10월, 총 20장)
- 족보 순위: 38광땡 > 18광땡 > 13광땡 > 장땡(10땡) ~ 1땡 > 알리 > 독사 > 구삥 > 장삥 > 세륙 > 갑오 > 끗수(1~8) > 망통
- 참가비(ante)를 낸 뒤 카드를 받고, 삥 / 콜 / 따당(레이즈) / 올인 / 다이 중 선택해 베팅
- 마지막까지 남거나 쇼다운에서 가장 높은 족보를 가진 플레이어가 팟을 획득
- 최대 5인, 최소 2인부터 플레이 가능 (4~5인 권장)
- 한 턴 제한시간 25초, 시간 초과 시 자동 다이

## 프로젝트 구조

- `server.js` - Express 정적 서버 + Socket.IO 이벤트 처리
- `game/hand.js` - 섯다 족보 판정 로직
- `game/Room.js` - 방/라운드/베팅 상태머신
- `public/` - 클라이언트 (로비, 테이블 UI, 채팅)
