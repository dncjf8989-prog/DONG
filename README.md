# 마나 듀얼 (Mana Duel)

하스스톤에서 영감을 받은 1인용(vs AI) 카드 대전 게임 초안입니다. 빌드 도구 없이 순수 HTML/CSS/JS로 동작합니다.

## 실행 방법

브라우저 보안 정책(ES 모듈의 CORS 제한)으로 인해 `index.html`을 파일로 직접 열기보다는 로컬 서버로 띄우는 것을 권장합니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 게임 규칙 요약

- 각 플레이어는 체력 30의 영웅으로 시작하며, 상대 영웅의 체력을 0 이하로 만들면 승리합니다.
- 매 턴 마나 결정석이 1개씩 늘어나며(최대 10), 턴이 시작되면 마나가 가득 채워지고 카드를 1장 뽑습니다.
- 손패에서 카드를 사용해 미니언을 소환하거나 주문을 시전합니다. 미니언은 소환된 턴에는 공격할 수 없습니다(단, **돌진** 키워드가 있으면 즉시 공격 가능).
- 전장에는 미니언을 최대 7마리까지 낼 수 있습니다.
- 키워드
  - **도발**: 상대는 도발을 가진 미니언이 있으면 반드시 그 미니언부터 공격해야 합니다.
  - **신성한 보호막**: 처음 받는 피해를 무효화합니다(보호막은 이후 소멸).
  - **돌진**: 소환된 턴에도 바로 공격할 수 있습니다.
  - **전투의 함성**: 미니언이 소환될 때 발동하는 효과.
  - **죽음의 메아리**: 미니언이 파괴될 때 발동하는 효과.
- 영웅 능력(공용, 마나 2): 대상에게 피해를 1 줍니다. 턴당 1회 사용 가능.
- 덱이 떨어지면 카드를 뽑을 때마다 점점 커지는 피로 피해를 영웅이 받습니다.

## 조작 방법

1. 손패의 카드를 클릭해 사용합니다. 대상이 필요한 카드는 클릭 후 영웅이나 미니언(빨간 테두리로 표시)을 클릭해 대상을 지정합니다.
   - 대상이 선택 사항인 카드는 "대상 없이 사용" 버튼으로 건너뛸 수 있습니다.
2. 내 전장의 공격 가능한 미니언(초록 테두리)을 클릭한 뒤, 공격할 대상(빨간 테두리)을 클릭합니다.
3. 영웅 초상화 옆의 영웅 능력 버튼을 클릭해 사용합니다.
4. 모든 행동이 끝나면 "턴 종료" 버튼을 눌러 상대(AI) 턴으로 넘깁니다.

## 코드 구조

- `index.html` — 페이지 레이아웃
- `css/style.css` — 스타일
- `js/cards.js` — 카드 데이터베이스와 덱 구성 로직
- `js/engine.js` — 턴 진행, 마나, 전투, 카드 효과 등 게임 규칙 엔진
- `js/ai.js` — 상대(AI)의 간단한 규칙 기반 의사결정 로직
- `js/main.js` — DOM 렌더링과 사용자 입력 처리
