# DONG

## 🏝 표류: 무인도 생존

실시간 타이머 없이, 행동을 선택할 때마다 시간(아침 → 낮 → 저녁 → 밤)이 흐르는 턴 기반 무인도 생존 게임입니다.

### 실행 방법

별도 빌드 없이 정적 파일만으로 동작합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.

### 게임 규칙 요약

- **시간**: 하루는 아침 / 낮 / 저녁 / 밤 4단계로 나뉘며, 행동(채집, 이동, 제작, 휴식)을 할 때마다 다음 단계로 넘어갑니다. 실시간으로 흐르지 않습니다.
- **스탯**: 체력 / 포만감 / 수분 / 정신력. 포만감이나 수분이 0이 되면 매 행동마다 체력이 깎이고, 체력이 0이 되면 게임 오버입니다.
- **장소**: 해변, 숲, 동굴, 난파선을 오가며 각기 다른 자원을 채집합니다.
- **제작**: 나무·돌·섬유 등을 모아 돌도끼, 낚싯대, 창, 모닥불, 쉼터, 뗏목 등을 제작합니다.
- **탈출**: 뗏목을 완성해 해변에서 탈출하거나, 희귀하게 발견되는 신호탄을 쏘아 구조되면 승리합니다.
- **저장**: 브라우저 로컬 저장소에 자동 저장되어 이어서 플레이할 수 있습니다.
