# DONG

## 메이플랜드 미니

간단한 브라우저 사이드스크롤 사냥 게임입니다. HTML5 Canvas와 순수 JavaScript로 제작되었으며 별도의 빌드 과정이 필요 없습니다.

### 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 (index.html을 더블클릭해서 직접 열어도 동작합니다).

### 조작법

- `←` / `→` : 이동
- `↑` / `Space` : 점프
- `Z` : 공격

플랫폼을 넘나들며 달팽이 몬스터를 처치해 경험치를 얻고 레벨업하세요. 몬스터를 모두 처치하면 잠시 후 다시 리스폰됩니다.
