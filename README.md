## 🏝 표류: 무인도 생존

실시간 타이머 없이, 행동을 선택할 때마다 시간(아침 → 낮 → 저녁 → 밤)이 흐르는 턴 기반 무인도 생존 게임입니다.

### 실행 방법

별도 빌드 없이 정적 파일만으로 동작합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.

### 게임 규칙 요약

- **시간**: 하루는 아침 / 낮 / 저녁 / 밤 4단계로 나뉘며, 행동(채집, 이동, 제작, 휴식)을 할 때마다 다음 단계로 넘어갑니다. 실시간으로 흐르지 않습니다.
- **스탯**: 체력 / 포만감 / 수분 / 정신력. 포만감이나 수분이 0이 되면 매 행동마다 체력이 깎이고, 체력이 0이 되면 게임 오버입니다.
- **장소**: 해변, 숲, 동굴, 난파선을 오가며 각기 다른 자원을 채집합니다.
- **제작**: 나무·돌·섬유 등을 모아 돌도끼, 낚싯대, 창, 모닥불, 쉼터, 뗏목 등을 제작합니다.
- **탈출**: 뗏목을 완성해 해변에서 탈출하거나, 희귀하게 발견되는 신호탄을 쏘아 구조되면 승리합니다.
- **저장**: 브라우저 로컬 저장소에 자동 저장되어 이어서 플레이할 수 있습니다.

## ⚽ 축구 리그 매니저

10개 구단이 겨루는 왕복 라운드로빈 리그(18라운드)를 감독으로서 지휘하는 시뮬레이션 게임입니다. 실시간이 아닌 라운드 단위로 진행됩니다. 단일 파일(`soccer-league.html`)로 동작합니다.

### 실행 방법

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/soccer-league.html 접속
```

또는 `soccer-league.html`을 브라우저로 직접 열어도 됩니다.

### 게임 규칙 요약

- **리그**: 10개 구단, 왕복 라운드로빈 18라운드. 승점(승3·무1·패0)과 득실차로 순위를 가립니다.
- **스쿼드**: 4-3-3 포메이션으로 선발 명단을 구성하고, 전술(공격적/균형/수비적)과 훈련 포커스(공격/수비/체력)를 매 라운드 선택합니다.
- **경기 엔진**: 포아송 분포 기반으로 득점 수를 계산하고, 득점자와 시간대가 포함된 매치 리포트를 즉시 보여줍니다.
- **이적시장**: 매 라운드 새로운 매물이 등장하며, 선수를 영입하거나 방출해 예산을 관리합니다.
- **부상/체력/사기**: 선발로 뛴 선수는 체력이 떨어지고, 드물게 부상을 당해 다음 라운드 활약이 줄어듭니다. 계속 벤치에만 앉히면 사기가 떨어지고, 너무 떨어지면 이적을 요청합니다 — 로테이션이 중요합니다.
- **라운드 이벤트**: 매 라운드 약 40% 확률로 이사회 요구, 스폰서 제안, 유망주 발견, 부상 위험 경고, 이적 요청, 국가대표 차출, 훈련장 투자 제안 등의 시나리오가 등장하며, 선택에 따라 예산·사기·스쿼드가 달라집니다.
- **라이벌전**: 시즌마다 라이벌 구단이 정해지고, 그 경기는 특별하게 연출되며 승리 시 팀 전체 사기가 크게 오릅니다.
- **매치 리포트**: 득점뿐 아니라 슈팅·선방·카드 등 장면과 전/후반 종료 마커까지 포함해 실제 경기 리포트처럼 보여줍니다.
- **득점왕**: 우리 팀 선수 개인 기록과 상대 팀 에이스의 득점을 함께 집계해 리그 득점왕 순위를 보여줍니다.
- **시즌 종료**: 18라운드가 끝나면 우승팀과 내 최종 순위, 득점왕이 발표되고, 스쿼드와 예산을 유지한 채 새 시즌을 시작할 수 있습니다.
